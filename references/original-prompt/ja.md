# XXD Panel 087 · Faithful reading translation

请将我上传的每一张照片分别制作成一张独立的高级设计海报，不多图拼接，每张照片单独输出。整体采用3:4竖版构图，上下两个区域高度严格1:1，各占画面50%。

上半部分保留原始照片，保持主体身份、结构、姿态、真实质感、自然光影和原有色彩氛围，仅进行轻微高级调色，使其具有艺术杂志、独立出版物与展览图像质感。为适配画幅，可自然扩展环境背景，但不得拉伸、扭曲或改变主体。

下半部分先分析照片中真正决定画面成立的**主体、轮廓、姿态、方向、空间关系与叙事焦点**，只保留3–5个最关键的视觉信息，再重构为具有中世纪现代主义气质的**限色丝网版画风肌理插画**。不要平均保留所有元素，也不要完整描摹原场景；应判断“什么最值得被看见、什么可以消失”，使主体高度概括后仍能一眼识别原物，同时比原照片拥有更清晰的视觉秩序。

构图以**大面积留白作为主动设计语言**。先根据主体的朝向、运动趋势、视觉重量和原图最有意味的空间关系确定落点，再组织版面，而不是机械居中。主体可偏置、缩小、局部裁切或靠近画面边缘，让其与大片空白形成尺度张力；留白可承担天空、距离、光线、海面、地面、沉默或时间感。通过不对称平衡、正负形、视觉轴线、疏密节奏和高低错位建立高级排版，使画面始终保持**一个明确焦点、一个主要方向和一片有意义的空白**。

主体使用剪影、几何形、简洁色块与少量关键结构重新塑造；环境只留下真正参与叙事的少数形态。画面采用 **Risograph / Screen Print–inspired textured illustration** 语言，通过 dry-brush、brayer texture、dragged ink、broken ink 与 uneven ink coverage 形成横向拖墨、飞白、断墨和粗粝油墨质感。可加入一个或少量几何圆形、色带、弧线或切面，与有机印刷肌理形成秩序对比，但不得成为装饰堆砌。

配色从上方照片中提取**最鲜明、最有生命力、最能代表主体气质的颜色关系**，重新压缩为2–4种专色。保留原图色相记忆，并适度提亮、提纯和增强清晰度，通过一个鲜明主色、一个深色结构色、一个浅色纸基色及必要时极少量点睛色建立层次。颜色明艳、有温度、有生命力，但仍具有版画油墨的综合色彩感，避免灰脏、莫兰迪化、荧光色、廉价糖果色与数字渐变。

文字根据主体分析后的**情绪、动作、地点、方向或隐喻**自由生成少量短文字，不限制语种和固定信息类型。字体使用**简洁、克制、略带铅字印刷误差与现代主义书刊气质的窄体字体**。文字不是附加说明，而应根据主体位置与留白结构重新排版：可压在大面积空白边缘、沿视觉轴线布置、与地平线对齐、贴近剪影边缘或形成一处很小的版式重心，让图形与文字共同完成画面的平衡。

整体呈现**大面积有意义的留白、鲜明主体、限色专色、剪影造型、几何秩序、干刷拖墨与克制图文排版**共同构成的高级版画海报气质。远看应先感受到留白、比例和构图，近看才发现粗粝油墨与印刷细节。避免主体过大填满画面、元素平均分布、复杂背景、多个视觉中心、装饰堆积、写实绘画、光滑矢量、3D渲染和模板化复古海报。
