# XXD Panel 087 オリジナルプロンプト · 日本語読解訳

アップロードした写真を1枚ずつ、それぞれ独立した上質なデザインポスターにしてください。複数画像を組み合わせず、写真ごとに個別出力します。全体は3:4の縦位置構図とし、上下2領域の高さを厳密に1:1、それぞれ画面の50%にしてください。

上半分には元の写真を残し、主体のアイデンティティ、構造、姿勢、リアルな質感、自然な光と影、元の色彩の雰囲気を維持します。色調補正はごく軽く上質にとどめ、アート雑誌、インディペンデント出版物、展覧会写真のような質感にしてください。画面比率に合わせて周囲の背景を自然に拡張してもかまいませんが、主体を引き伸ばしたり、歪めたり、改変したりしてはいけません。

下半分では、写真の中で最も識別性の高い**主体、輪郭、構造、姿勢、物語上の関係**を抽出し、実際に触れられそうな **Physical String-based Systems Map / Tangible Node-link Visualization** へ変換します。元の対象をそのまま描写せず、主体を少数の意味あるノードと関係へ分解してください。主要な輪郭、構造の転換点、動作の方向、空間的位置、環境の手掛かりを画鋲状の Nodes とし、それらを実物の糸による Edges / Links で結びます。これにより、元写真の視覚的関係を物理的なネットワークとして再び立ち現れさせながら、元の主体のアイデンティティと構造をかすかに判別できる状態に保ちます。

構図では、明確な1つの**核心ノードまたは核心関係**を視覚の軸とし、残りのノードを主体の構造に沿って自然に展開します。糸は無作為に絡ませず、元画像の方向、比率、遠近、接続、物語の論理に基づいて関係を築いてください。一部のノードは放射、集積、三角形、多角形、領域をまたぐ接続を形成し、多数の単純な関係から自然に **emergent geometry** が生まれるようにします。全体は複雑でありながら秩序を保ち、中心の関係を密に、外側へ向かうほど徐々に疎にしてください。十分なネガティブスペースを残し、画面全体を埋め尽くさないようにします。

素材には、実在する物理的インスタレーションの感触が必要です。小さな画鋲、縫い目、綿糸または細い紐、紙ラベル、手書きの痕跡、実物の厚紙表面を使い、糸の張りのわずかな違い、ノードの高さ、交差による遮蔽、針目の影、手仕事の誤差を残してください。全体はアートディレクションされたリサーチウォール、システムデザインの実験、または情報アートのインスタレーションのように見せ、コンピューターで描いたネットワーク図にはしません。サイバー UI、デジタルに発光する線、安っぽい捜査ボードの印象も避けてください。

糸には、主要な関係色として**鮮やかでありながら抑制の利いた朱赤、コーラルレッド、または暖色系の赤**を用い、自然な白、暖かい白、淡いグレー、または上部写真全体の色温度と調和するごく淡い背景を広く取って、視覚的な緊張感を生み出します。画鋲、紙タグ、少量の印には、上部写真から抽出した部分的な特徴色を小さな面積で呼応させてもかまいません。全体の色はクリーンでモダン、生命感のあるものとし、暗褐色、汚れた古び、血のような赤の恐怖感、過度なヴィンテージ加工を避けてください。

文字はシステム内へ **Hand-lettered Annotation** として自由に介入させ、固定のタイトル、場所、年、メニュー風の情報をあらかじめ設定しません。写真の主体、動作、位置、感情、関係、比喩に基づいて、少数のキーワード、短い語句、矢印、囲み注記、極小の説明を自由に生成し、ノードの近く、糸の交点、または余白へ直接書き込みます。字体は**小さく、力が抜け、リサーチノートらしさとわずかな筆記の揺らぎを持つ手書き注釈文字**とし、観察の過程で自然に残された思考の痕跡のように見せながら、上質なエディトリアルデザインの抑制と可読性を保ってください。
